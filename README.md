# SELO AUDIO MASTER AI

تطبيق مجاني لتحويل النص العربي إلى ملف صوتي، بدون مفتاح API أو اشتراك مدفوع.

## النسخة الويب

- توليد صوت عربي فعلي داخل المتصفح باستخدام نموذج Nabra-7M-Distill، دون إرسال النص إلى خدمة توليد سحابية.
- لا يلزم مفتاح API. في أول استخدام يُنزّل المتصفح مكونات النموذج (قرابة 16 MB بصيغة fp16، إضافةً إلى ملفات التشغيل)، ثم يحتفظ بها في ذاكرته المؤقتة.
- يدعم النموذج العربية الفصحى بصوت واحد؛ لا يدعم اللهجات أو اختيار عدة أصوات حاليًا.
- يستمع المستخدم للنتيجة وينزّلها بصيغة WAV.
- يحتاج الإنترنت في أول تحميل للنموذج، وبعد التخزين المؤقت يمكن أن يعمل محليًا بحسب المتصفح وإعداداته.

## نسخة Android

- تستخدم محرك تحويل النص إلى كلام الموجود على الهاتف، ولا تحتاج مفتاح API أو ترسل النص إلى Gemini.
- تختار صوتًا عربيًا مثبّتًا على الجهاز، وتحوّل النص إلى WAV مع إمكانية تشغيله وحفظه.
- جودة الصوت وتوفّر الأصوات العربية يعتمدان على محرك النطق والأصوات المثبّتة في الهاتف. يمكن تنزيل صوت عربي من إعدادات تحويل النص إلى كلام في Android.

## تشغيل وبناء

- يعمل خادم الويب بـ FastAPI: `pip install -r requirements.txt` ثم `uvicorn app.main:app --reload`.
- إعداد Render يستخدم الخطة المجانية.
- GitHub Actions workflow باسم **Android APK** يبني Debug APK ويرفعه كـ Artifact باسم `selo-audio-master-android-debug`.

## ملاحظة عن جودة الصوت

هذه النسخة لا تستخدم خدمة مدفوعة. نموذج الويب الحالي فصحى وبصوت واحد، ومحرك Android يختلف حسب الهاتف. الأداء الطبيعي يتأثر بوضوح النص والتشكيل وقوة الجهاز أو الصوت المثبّت؛ لذلك لا نضمن جودة مماثلة للخدمات التجارية أو أداءً مطابقًا لمتحدث بشري.
