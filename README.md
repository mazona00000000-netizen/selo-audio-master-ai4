# SELO AUDIO MASTER AI

مشروع استوديو صوت عربي، مع تطبيق Android أصلي كمسار الاستخدام الأساسي على الهاتف.

## تطبيق Android الحالي

تمت إضافة تطبيق Android أصلي باسم **SELO AUDIO MASTER AI** باستخدام Java وAndroid SDK، ويستهدف Android 8.0 (API 26) فما أحدث.

الوظائف الموجودة في النسخة التأسيسية:
- اختيار ملفات صوت من الهاتف عبر منتقي ملفات Android.
- تشغيل وإيقاف الملفات الصوتية.
- التحكم في سرعة التشغيل ومستوى الصوت أثناء الاستماع.
- تسجيل التعليق الصوتي من ميكروفون الهاتف بعد إذن المستخدم.
- حفظ التسجيلات بصيغة M4A وتصديرها إلى مجلد الموسيقى.
- واجهة عربية داكنة بلمسات ذهبية.

**حدود النسخة الحالية بوضوح:** التحكم في السرعة ومستوى الصوت يطبق أثناء التشغيل فقط ولا ينشئ ملفًا صوتيًا معالجًا. مؤثرات EQ والضغط وإزالة الضوضاء، وفصل طبقة الصوت عن السرعة، ومحرر السكريبت المتقدم، ومحرك تحويل النص إلى كلام الحقيقي لم تُدمج بعد. لن نعرض أيًا منها على أنها تعمل قبل تنفيذها واختبارها.

## بناء ملف APK

يوجد GitHub Actions workflow باسم **Android APK** يقوم ببناء نسخة Debug APK تلقائيًا عند تحديث ملفات Android، ثم يرفع الملف كـ Artifact باسم `selo-audio-master-android-debug`.

للحصول على الملف:
1. افتح تبويب Actions في مستودع GitHub.
2. اختر Android APK.
3. افتح أحدث تشغيل ناجح.
4. نزّل Artifact باسم `selo-audio-master-android-debug`.
5. فك ضغط الملف وثبّت `app-debug.apk` على هاتف Android. قد يطلب الهاتف السماح بالتثبيت من مصدر المتصفح أو مدير الملفات.

رابط المستودع: https://github.com/mazona00000000-netizen/selo-audio-master-ai4

## نسخة الويب / API

ما زالت نسخة FastAPI والواجهة التجريبية موجودة في المستودع، لكنها ليست شرطًا لتشغيل تطبيق Android ولا تحتاج خدمة Render لاستخدام الوظائف المحلية الأساسية.

## متطلبات البناء

- JDK 17
- Gradle 8.9
- Android SDK Platform 35
- Android Build Tools 35.0.0

## خارطة التطوير

1. إكمال معالجة صوت فعلية وتصدير نسخة WAV معالجة.
2. إضافة محرر سكريبت وعلامات الأداء والمشاعر إلى تطبيق Android.
3. دمج محرك TTS حقيقي مع إدارة أصوات وإعدادات ثابتة.
4. اختبار الأداء واستهلاك البطارية والتوافق على أجهزة Android مختلفة.
