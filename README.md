# SELO VOICE ACTOR AI

تطبيق Android لتحويل النص إلى أداء صوتي باستخدام Gemini TTS.

## الوظائف الحالية في نسخة Android

- كتابة النص المراد تحويله إلى كلام.
- اختيار خامة صوت من أصوات Gemini المسبقة.
- اختيار توجيه الأداء: درامي، حزين، خوف، غضب، تشويق، هادئ، إخباري، وغيرها.
- إضافة توجيه حر لطريقة الإلقاء واللهجة والسرعة والوقفات.
- توليد ملف WAV فعلي عبر Gemini 3.8 Flash TTS.
- تشغيل النتيجة وحفظها في Music/SELO Voice Actor.

## متطلبات التشغيل

- اتصال إنترنت.
- مفتاح Gemini API صالح من Google AI Studio.
- قد تخضع طلبات التوليد لحصص الاستخدام والتسعير وشروط توفر النموذج في حساب Google.

عند فتح التطبيق، الصق مفتاح Gemini API في خانته، ثم اكتب النص واختر الصوت والأداء واضغط «توليد الأداء الصوتي». لا يتم تضمين المفتاح داخل APK أو حفظه في التطبيق.

## البناء

## ملاحظات

- المحرك الحالي هو Gemini 3.8 Flash TTS عبر Gemini Interactions API.
- الواجهة الحالية تولّد متحدثًا واحدًا لكل طلب. دعم الحوار متعدد الشخصيات، إدارة مكتبة الأصوات المخصصة، وتقسيم النص إلى مقاطع مع تحكم مستقل في الأداء ستأتي في مرحلة لاحقة.
- مفاتيح API حساسة؛ لا تشارك مفتاحك مع أي شخص.
